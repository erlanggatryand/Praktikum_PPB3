# Praktikum PPB3 - Flutter Products App

## Deskripsi
Aplikasi Products berbasis Flutter yang terhubung dengan backend API. Aplikasi ini dibuat untuk memenuhi tugas Praktikum Pemrograman Perangkat Bergerak (PPB3).

## Fitur Aplikasi
Aplikasi ini memiliki fitur CRUD (Create, Read, Update, Delete):

- **Create:** Menambahkan produk baru.
- **Read:** Menampilkan daftar dan detail produk.
- **Update:** Mengubah informasi produk.
- **Delete:** Menghapus produk dengan konfirmasi.

## Teknologi yang Digunakan
- Flutter
- Dart
- Provider (State Management)
- GoRouter (Navigation)
- REST API (Backend)
